# Market Analytics Engine

A Java and PostgreSQL system for ingesting historical market data and performing market and portfolio analysis.

## Planned Features

- Historical market-data ingestion
- Relational database for market data
- SQL-based market analysis
- Portfolio tracking and performance analysis
- Query optimization and database indexing
- Java application for interacting with the database

## Tech Stack

- Java
- PostgreSQL
- SQL
- JDBC
- Maven

In development.
